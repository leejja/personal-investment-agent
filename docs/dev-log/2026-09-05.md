  않고 바로 인사에 응답하는 문제를 확인함 → trigger를 "첫 substantive turn"에서 **"첫 user turn"**
  (내용·중요도·substantive 여부와 무관, `hi`/`hello`/casual message 포함)으로 변경. 4단계 확인

  명시적으로 금지
- repository state를 이전 conversation context / memory만으로 추론하는 것을 금지
- README와 최신 dev-log를 canonical handoff로 사용하되, 실제 git/repository state와의 정합성도
  확인하도록 명시
- documentation과 repository state 사이에 의미 있는 conflict가 있으면 임의 수정하지 않고 먼저
  사용자에게 보고하도록 명시
- 이 protocol은 Claude Code 실행 직후 사용자 입력 없이 tool을 선제 실행하는 목적이 아니라, 첫
  user turn에 응답하기 전에 반드시 수행하는 lifecycle로 정의
