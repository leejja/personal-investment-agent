# 다음 세션 추천 시작점

## Stock Research Agent v1

다음 단계부터 API 연결 중심 개발에서 실제 Agent Layer 구현으로 이동한다.

첫 Agent로 `Stock Research Agent`를 구현하는 방향을 추천함.

현재 확보된 입력:

### Kiwoom

get_stock_info()

- 현재가
- 등락률
- 거래량
- PER
- PBR
- ROE
- EPS
- BPS
- 250일 고가/저가

### OpenDART

get_key_financials()

- 매출
- 영업이익
- 순이익
- 자산
- 부채
- 자본

### Portfolio

get_portfolio_context()

- 보유 여부
- 보유수량
- 평단
- 현재가
- 평가금액
- 손익
- 수익률
- 포트폴리오 비중

따라서 Stock Research Agent v1은 우선:

stock_code
    ↓
Stock Research Agent
    ├── get_stock_info
    ├── get_key_financials
    └── get_portfolio_context
            ↓
     Stock Analysis Result

구조로 설계할 수 있다.

Market Agent는 현재 기준금리 외 시장 데이터가 부족하기 때문에
Stock Research Agent v1 이후 시장 데이터 API를 확장하면서 구현하는 방향이 적절하다.

Portfolio Strategy Agent는 Stock Research Agent 결과가 만들어진 뒤 구현한다.

예상 순서:

1. Stock Research Agent v1
2. Market 데이터 확장
3. Market Agent
4. Portfolio Strategy Agent
5. Recommendation / Strategy Logic
6. Supervisor / Router
