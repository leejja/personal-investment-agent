## 1. Project Goal

    개인의 실제 투자 의사결정을 지원하는 **Multi-Agent 기반 개인화 투자 분석 시스템**을 개발한다.

    자동매매가 핵심 목적이 아니라 다음 흐름을 통해 근거가 추적 가능한 투자 전략을 생성하는 것이 목표다.

    ```text
    Market Environment
    ↓
    Stock Analysis
    ↓
    Portfolio Impact
    ↓
    Personalized Investment Strategy
    ```

    최종 Agent 구조:

    ```text
    User
    │
    ▼
    Supervisor / Router
    │
    ┌───────────────┼───────────────┐
    ▼               ▼               ▼
    Market Agent    Stock Research    Portfolio
    Agent        Strategy Agent
    │               │               │
    └───────────────┼───────────────┘
    ▼
    Investment Strategy
    ```

## 7. Settings Implementation

    `app/config.py`를 생성했다.

    현재 구현:

    ```python
    from pydantic_settings import BaseSettings, SettingsConfigDict


    class Settings(BaseSettings):
        openai_api_key: str = ""
        kiwoom_app_key: str = ""
        kiwoom_secret_key: str = ""
        ecos_api_key: str = ""
        opendart_api_key: str = ""

        model_config = SettingsConfigDict(
                env_file=".env",
                env_file_encoding="utf-8",
                case_sensitive=False,

settings = Settings()
    ```

## 8. Architecture Decision

    외부 API 호출 코드를 Agent 내부에 직접 구현하지 않는다.

    기본 구조:

    ```text
    Agent
    │
    ▼
    Service
    │
    ▼
    MCP / External API
    ```

    예:

    ```text
    Market Agent
    │
    ▼
    ECOS Service
    │
    ▼
    한국은행 ECOS API
    ```

    이렇게 구성하여 다음을 분리한다.

    * Agent reasoning
    * Data acquisition
    * External API implementation
    * Data model
    * Testing

## 10. Evidence Tracking

    프로젝트의 핵심 설계 원칙 중 하나는 **Traceability**다.

    따라서 Agent 분석 결과에는 가능한 한 분석 근거를 함께 저장한다.

    공통 모델로 다음 구조를 사용할 예정이다.

    ```text
    Evidence
    ├── source
    ├── description
    └── timestamp
    ```

    예:

    ```python
    Evidence(
            source="ECOS",
            description="한국은행 기준금리 데이터",
            )
    ```

    또는:

    ```python
    Evidence(
            source="OpenDART",
            description="삼성전자 반기보고서",
            )
    ```

    최종 Strategy가 어떤 데이터와 Agent 판단에서 생성되었는지 추적할 수 있도록 한다.


    예정 코드 구조:

    ```python
    from datetime import datetime
    from enum import Enum

    from pydantic import BaseModel, Field


    class RiskLevel(str, Enum):
        LOW = "low"
        MEDIUM = "medium"
        HIGH = "high"


        class AnalysisConfidence(str, Enum):
            LOW = "low"
            MEDIUM = "medium"
            HIGH = "high"


            class Evidence(BaseModel):
                source: str
                description: str
                timestamp: datetime | None = None


                class UserRequest(BaseModel):
                    question: str = Field(min_length=1)
                    symbols: list[str] = Field(default_factory=list)
                             ```

                             구현 후:

                             ```bash
                             python -m py_compile app/models/common.py
                             ```
